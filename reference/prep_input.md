# Convert sf and sftime objects to stdt format

Convert sf and sftime objects to stdt format

## Usage

``` r
prep_input(input)
```

## Arguments

- input:

  An sf, sftime, SpatVector or SpatRasterDataset object

## Value

A data.table object with `lon`, `lat`, `time` and a `crs` attribute
