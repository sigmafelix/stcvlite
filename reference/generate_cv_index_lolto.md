# Generate spatio-temporal cross-validation index leave-one-location-time-out)

Generate spatio-temporal cross-validation index
leave-one-location-time-out)

## Usage

``` r
generate_cv_index_lolto(covars)
```

## Arguments

- covars:

  data.frame-like object with `lon`, `lat`, and `time` columns. See
  [`prep_input()`](https://sigmafelix.github.io/stcvlite/reference/prep_input.md)
  for details.

## Value

An integer vector.
